Library reference

dabscm tutorials

Tutorials for learning Scheme with dabscm and for getting things done with its libraries. They complement the library reference: the reference lists every procedure, the tutorials show how to put them together, with worked examples.

Every tested example in these tutorials is run by dabscm's test suites, on the JVM, .NET and native implementations, so the code works as shown.

Where to start

  • New to Scheme? Read the basics in order. Each chapter builds on the previous one.
  • Know Scheme, new to dabscm? Skim getting started, then go to the techniques you need.
  • Looking for a specific task? See find by task below.

Basics

  1. Getting started: scripts, the REPL, one-liners, scm fmt/scm lint, native executables
  2. Expressions and values: numbers, booleans, symbols, strings, display versus write, equality
  3. Definitions and procedures: define, lambda, let, optional arguments, closures
  4. Pairs and lists: building lists, map/filter/fold, association lists, quasiquote
  5. Control flow and recursion: cond, case, named let, tail calls, do
  6. Vectors, bytevectors and other data: indexed and binary data, choosing a structure
  7. Higher-order programming: closures, composition, cut, memoization
  8. Records: define-record-type, collections of records, multiple values
  9. Errors and exceptions: error, guard, raise, dynamic-wind
  10. Libraries and programs: import, define-library, project layout
  11. Macros and pattern matching: syntax-rules, match, a small interpreter
  12. Continuations, generators and laziness: call/cc, SRFI 158 generators, streams

Techniques

  1. Strings and text: searching, splitting, padding, regular expressions, formatting, templates
  2. Characters and Unicode: character classes, case, character sets, UTF-8
  3. Files and directories: reading and writing, encodings, paths, globbing, finding files
  4. Hash tables and dictionaries: key equality, counting, grouping, SRFI 69 and 125
  5. Sorting and searching: sorting by keys and several criteria, binary search, median
  6. Iteration patterns: choosing the loop construct, folds, windows, generator pipelines
  7. Dates and times: ISO timestamps, date arithmetic, weekdays, durations
  8. Structured data: JSON, XML, TOML, CSV
  9. Command-line programs: options, help, exit codes, colors, logging
  10. Testing your code: (scm test), test layout, all three implementations
  11. Concurrency: threads, mutexes, a work queue, errors in threads
  12. The system: running programs, environment, platform

Running the examples yourself

Copy a code block into a file, keep the import from the chapter's first block, and run it with scm file.scm. Lines ending in ;; => value show what an expression returns; ;; prints: shows what it writes. Every example is run as a test on the JVM, .NET and native implementations; the few that need a library dabscm native lacks (the REPL support, the profiler) are tested on the JVM and .NET only.
