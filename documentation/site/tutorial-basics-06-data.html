Vectors, bytevectors and other data

Vectors

A vector is a fixed-size array: access by index takes constant time, whatever the size. Vectors are written #(...):

(import (scheme base) (scheme char)
        (only (srfi 133) vector-fold vector-index vector-count))

(define v (vector 'a 'b 'c))
(vector-ref v 1)                  ;; => b
(vector-length v)                 ;; => 3
(vector-set! v 1 'beta)
v                                 ;; => #(a beta c)
(make-vector 3 0)                 ;; => #(0 0 0)
(vector->list #(1 2 3))           ;; => (1 2 3)
(list->vector '(1 2 3))           ;; => #(1 2 3)
(vector-map (lambda (x) (* x x)) #(1 2 3)) ;; => #(1 4 9)
(define w (make-vector 2 0))
(vector-fill! w 'x)
w                                 ;; => #(x x)

A vector literal like #(1 2 3) is a constant; use vector or make-vector for one you want to change.

Example: a histogram

Count dice rolls by face. A vector indexed by the face value is the natural counter:

(define rolls '(3 6 1 6 2 6 5 3 1 4 6 2))

(define (histogram values size)
  (let ((counts (make-vector size 0)))
    (for-each (lambda (x)
                (vector-set! counts x (+ 1 (vector-ref counts x))))
              values)
    counts))

(histogram rolls 7)               ;; => #(0 2 2 2 1 1 4)

Face 6 came up four times. (srfi 133) adds many vector operations; here vector-index finds the most frequent face:

(define counts (histogram rolls 7))
(define top (vector-fold (lambda (m x) (max m x)) 0 counts))
(vector-index (lambda (x) (= x top)) counts) ;; => 6
(vector-count even? counts)       ;; => 5

Bytevectors

A bytevector holds bytes (0 to 255): file contents, network messages, images. It is written #u8(...):

(define header (bytevector 137 80 78 71))
(bytevector-u8-ref header 1)      ;; => 80
(bytevector-length header)        ;; => 4
(utf8->string (bytevector 72 105)) ;; => "Hi"
(string->utf8 "é")                ;; => #u8(195 169)
(bytevector-append #u8(1 2) #u8(3)) ;; => #u8(1 2 3)

string->utf8 and utf8->string convert between text and its UTF-8 bytes; "é" takes two bytes. The first bytes of every PNG file are 137 80 78 71 ("x89PNG"), so that is how a program recognizes one. Files shows reading and writing binary files.

Characters and strings in brief

(char->integer #\A)               ;; => 65
(integer->char 955)               ;; => #\λ
(string #\a #\b)                  ;; => "ab"
(make-string 3 #\-)               ;; => "---"
(string-copy "hello" 1 3)         ;; => "el"
(string-map char-upcase "shout")  ;; => "SHOUT"
